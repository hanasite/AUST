# AUST 手机端 UI v2.0 实施计划（Plan 1/3）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把手机端 `www/index.html` 从旧版（蓝白 Material 风 + emoji）重构为已确认的 A1 扁平风格（Twitter 清新感 + 内嵌 Inter + Lucide 图标），并修复常用链接页全部已知问题；WiFi 卡片界面与连接流程（mock 数据源）同步落地。

**Architecture:** 单文件 WebView 应用（Capacitor 6）。本次先建立仓库工作副本 `AUST/phone/`（含 android 工程），全部改动在该副本进行并逐任务提交。index.html 采用"增量替换、文件始终可运行"策略：设计令牌与图标 sprite 先行，然后逐页迁移（首页 → 自助系统 → 常用链接），旧 CSS 只在对应区块迁移完成后删除。元素 ID 保持稳定，最大限度复用现有 JS 逻辑。

**Tech Stack:** Capacitor 6 / 单文件 HTML+CSS+JS（ES2020）/ Java（仅注册位，WiFi 插件在 Plan 2）/ Gradle 8.7（Plan 1 Task 1 升级）+ JBR 21。

- [ ] **Step 3: 写 sprite 生成脚本**

`phone/tools/build-sprite.mjs`：

```js
import fs from 'node:fs';
import path from 'node:path';

const dir = new URL('./icons/', import.meta.url).pathname.replace(/^\/([A-Za-z]:)/, '$1');
const out = new URL('./sprite-out.html', import.meta.url).pathname.replace(/^\/([A-Za-z]:)/, '$1');
const ids = { 'chart-column':'ic-chart', 'refresh-cw':'ic-refresh', 'graduation-cap':'ic-gradcap',
  'book-open':'ic-book', 'smartphone':'ic-phone', 'circle-alert':'ic-alert' };

const files = fs.readdirSync(dir).filter(f => f.endsWith('.svg'));
const symbols = files.map(f => {
  const name = f.replace('.svg', '');
  const id = ids[name] || ('ic-' + name);
  let svg = fs.readFileSync(path.join(dir, f), 'utf8');
  const viewBox = (svg.match(/viewBox="([^"]+)"/) || [, '0 0 24 24'])[1];
  const inner = svg.replace(/^[\s\S]*?<svg[^>]*>/, '').replace(/<\/svg>[\s\S]*$/, '')
    .replace(/\s*class="[^"]*"/g, '').replace(/\s*(width|height)="[^"]*"/g, '').trim();
  return `  <symbol id="${id}" viewBox="${viewBox}">${inner}</symbol>`;
}).sort();
fs.writeFileSync(out, `<svg xmlns="http://www.w3.org/2000/svg" style="display:none">\n${symbols.join('\n')}\n</svg>\n`);
console.log('symbols:', symbols.length);
```

```js
function normalizeUrl(input){
  const s=(input||'').trim();
  if(!s) return null;
  if(/^https?:\/\//i.test(s)) return s;
  if(/^[\w-]+(\.[\w-]+)+(\/.*)?$/.test(s)) return 'https://'+s;
  return null;
}
function escHtml(s){return String(s).replace(/[&<>"']/g,c=>({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c]));}
function ensureSections(data, defaults){
  const names=new Set(data.map(s=>s.section));
  const missing=defaults.filter(d=>!names.has(d.section)).map(d=>({section:d.section,items:JSON.parse(JSON.stringify(d.items))}));
  return data.concat(missing);
}
```

```js
const WifiFlow = {
  state:'idle', scanTimer:null,
  async refresh(){ /* scan → 渲染 #wifi-list → 更新 f-foot 时间戳 */ },
  async onConnect(ssid){
    const n=this.find(ssid);
    if(n.secured && !cfg.saved[ssid]) return this.showPasswordSheet(n);
    return this.doConnect({ssid,password:cfg.saved[ssid],secured:n.secured,save:true});
  },
  async doConnect(opts){
    this.renderConnecting(opts.ssid);           // 步骤条: saving ✓ → awaiting…
    await Wifi.connect(opts);
    const ok=await this.waitConnected(opts.ssid,20000);  // 2s 轮询 getStatus
    ok?this.success(opts):this.failed(opts,'未找到网络或系统未确认');
  },
  success(opts){ if(opts.save) saveToCfg(opts); this.closeSheet(); showSnack('✅ 已连接并保存，下次一键即连'); this.refresh(); },
  failed(opts,reason){ this.renderFailed(opts.ssid,reason); }
};
```
