# AUST 校园认证助手 · Capacitor APK 打包指南

## 环境要求

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | >= 18 | https://nodejs.org |
| Android Studio | Ladybug 2024+ | https://developer.android.com/studio |
| JDK | 17（Android Studio 内置） | 无需单独安装 |

---

## 第一步：安装 Node.js

去 https://nodejs.org 下载 LTS 版，安装后验证：

```bash
node -v   # 应显示 v18.x 或更高
npm -v
```

---

## 第二步：安装 Android Studio

1. 下载并安装 Android Studio
2. 打开后进入 **SDK Manager**（右上角齿轮图标）
3. 安装以下组件：
   - Android SDK Platform **34**
   - Android SDK Build-Tools **34.x**
   - Android SDK Command-line Tools（latest）
4. 配置环境变量（Windows）：
   ```
   ANDROID_HOME = C:\Users\你的用户名\AppData\Local\Android\Sdk
   Path 中添加：
     %ANDROID_HOME%\platform-tools
     %ANDROID_HOME%\cmdline-tools\latest\bin
   ```

---

## 第三步：初始化 Capacitor 项目

把项目文件夹（`aust-app/`）放到你电脑上，然后打开终端进入该目录：

```bash
cd aust-app

# 安装依赖
npm install

# 添加 Android 平台（首次执行）
npx cap add android
```

执行完毕后，目录里会多出一个 `android/` 文件夹，这就是 Android 工程。

---

## 第四步：配置网络安全策略（重要！允许 HTTP）

DrCOM 认证服务器使用的是 HTTP（非 HTTPS），Android 9+ 默认禁止明文 HTTP，
需要手动配置：

1. 把 `android-network-security-config.xml` 复制到：
   ```
   android/app/src/main/res/xml/network_security_config.xml
   ```
   （`xml/` 文件夹若不存在就新建）

2. 打开 `android/app/src/main/AndroidManifest.xml`，
   在 `<application` 标签里加一行：
   ```xml
   <application
       ...
       android:networkSecurityConfig="@xml/network_security_config"
       android:usesCleartextTraffic="true"
       ...>
   ```

3. 同时确认 `<uses-permission>` 有网络权限（Capacitor 默认会加，确认一下）：
   ```xml
   <uses-permission android:name="android.permission.INTERNET" />
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
   ```

---

## 第五步：同步代码到 Android 工程

每次修改 `www/index.html` 后都要执行：

```bash
npx cap sync android
```

---

## 第六步：用 Android Studio 编译 APK

```bash
# 用 Android Studio 打开 android/ 工程
npx cap open android
```

Android Studio 打开后：

1. 等待 Gradle 同步完成（第一次较慢，需下载依赖）
2. 菜单 → **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
3. 编译完成后点提示框里的 **locate** 找到 APK 文件
4. APK 路径通常在：
   ```
   android/app/build/outputs/apk/debug/app-debug.apk
   ```

---

## 第七步：安装到手机

```bash
# 用 adb 安装（手机开启 USB 调试后连接电脑）
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

或者直接把 APK 文件传到手机，用文件管理器安装（需允许"安装未知来源应用"）。

---

## 发布正式版（可选，用于分发给同学）

在 Android Studio 中：
1. **Build → Generate Signed Bundle / APK**
2. 选择 **APK** → 创建或选择签名 keystore
3. 选择 **release** 构建类型
4. 编译出 `app-release.apk`，体积更小，可正常分发

## 目录结构说明

```
aust-app/
├── www/
│   └── index.html          ← 所有 UI 和逻辑在这一个文件里
├── android/                ← npx cap add android 后自动生成
│   └── app/src/main/
│       ├── AndroidManifest.xml   ← 需手动加网络安全配置
│       └── res/xml/
│           └── network_security_config.xml  ← 从根目录复制过来
├── capacitor.config.json   ← Capacitor 配置
└── package.json
```

## 常见问题

**Q: `npx cap add android` 报错 "Android Studio not found"**
A: 确认 `ANDROID_HOME` 环境变量已设置，重启终端后重试。

**Q: Gradle 下载超慢**
A: 在 `android/gradle.properties` 里加代理，或用手机热点换网络。
   也可以把 `android/build.gradle` 里的 `google()` 仓库换成国内镜像：
   ```
   maven { url 'https://maven.aliyun.com/repository/google' }
   maven { url 'https://maven.aliyun.com/repository/central' }
   ```

**Q: DrCOM 认证还是失败**
A: 确认手机已连接校园网（WiFi 或有线热点），然后在应用日志里看具体报错。
   HTTP 明文流量需要完成"第四步"的网络安全配置，否则请求会被 Android 系统拦截。

**Q: 验证码图片显示不出来**
A: Portal 登录需要 HTTPS，确认 `xgmm.aust.edu.cn` 可访问。
   图片通过 `CapacitorHttp.get + responseType: arraybuffer` 获取后转 base64 显示，
   不依赖 WebView 跨域。

**Q: 想修改 UI / 添加功能**
A: 直接编辑 `www/index.html`，然后 `npx cap sync android`，
   再在 Android Studio 里重新 Build APK 即可。
